# Assignment #4 — Forms and Validation

Учебный мини-сайт по курсу **Web Technologies**. Проект показывает последовательное развитие форм: от простой HTML-структуры до Bootstrap-формы с проверкой данных и обратной связью.

## Страницы

- `index.html` — описание проекта и навигация по заданиям.
- `task0.html` — простая контактная форма с корректными `label`, `input` и `textarea`.
- `task1.html` — контактная форма с нативной HTML5-валидацией (`required`, `type`, `minlength`, `maxlength`).
- `task2.html` — та же идея, оформленная Bootstrap 5.3 с адаптивной сеткой и helper text.
- `task3.html` — JavaScript-проверка имени, email и сообщения с классами `is-valid`, `is-invalid` и feedback-сообщениями.
- `task4.html` — регистрационная форма с паролем, совпадением паролей, radio buttons, checkboxes, select и Reset.

## Технологии

- HTML5
- CSS3
- Bootstrap 5.3.3 через CDN
- Vanilla JavaScript

Сборщики, сервер и дополнительные зависимости не используются.

## Запуск локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Для более удобной разработки можно открыть папку в VS Code и запустить `index.html` через расширение Live Server.

Для Bootstrap нужен доступ к CDN. При проверке без интернета структура HTML и базовый CSS останутся доступными, но Bootstrap-оформление не загрузится.

## Как проверить формы

1. В `Task 0` убедитесь, что у каждого поля есть видимая подпись.
2. В `Task 1` попробуйте отправить пустую форму и введите неправильный email — браузер покажет встроенные сообщения.
3. В `Task 2` уменьшите ширину окна и проверьте, что поля переходят в одну колонку.
4. В `Task 3` отправьте пустую или неправильную форму, затем заполните имя (2–60 символов), корректный email и сообщение (10–500 символов).
5. В `Task 4` проверьте обязательные поля, email, пароль от 8 до 64 символов с цифрой и несовпадающие пароли. Кнопка `Reset` должна очистить значения и стили проверки.

## Важное замечание

Это демонстрационный учебный проект. Backend не подключён: формы не отправляют реальные данные и не создают аккаунты. Пароли проверяются только в браузере, не выводятся на экран и нигде не сохраняются.

## Публикация

### GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите публикацию из ветки `main` (папка `/root`).
4. Сохраните настройки и откройте URL, который покажет GitHub Pages.

### Netlify

1. Войдите в Netlify и выберите **Add new site → Import an existing project**.
2. Подключите GitHub-репозиторий.
3. Оставьте Build command пустой, а publish directory укажите как корень проекта (`.`).
4. Запустите публикацию.
